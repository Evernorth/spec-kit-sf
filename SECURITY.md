# Security Policy

Evernorth takes the security of our open-source software seriously. We appreciate the efforts of security researchers and the community in helping us keep our projects safe.

## Supported Versions

Only the latest published release of this extension receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **DO NOT** report it via a public GitHub Issue or Pull Request.

Instead, please submit a responsible disclosure report to the Evernorth Security Team:

* **Email**: [opensource@evernorth.com](mailto:opensource@evernorth.com)
* **Alternative**: Report via GitHub's Private Vulnerability Reporting feature on this repository.

### What to Include in Your Report

To help us triage and investigate the issue as quickly as possible, please include:
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept (PoC) demonstrating how to reproduce the issue.
3. Affected versions and environments (e.g., OS, Salesforce CLI version).
4. Any potential mitigations or remediations you have identified.

### Response Timeline

* **Acknowledgment**: We aim to acknowledge receipt within 48 business hours.
* **Triage & Assessment**: We will assess the severity and work on a fix within 10 business days.
* **Public Disclosure**: We coordinate public disclosure with the reporter once a fix is validated and released.
